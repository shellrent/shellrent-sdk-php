**tb_size** | **int** | Storage size, in TB. The allowed sizes depend on the Object Storage service: from its minimum to its maximum quantity, in steps of 1 TB up to 5 TB and of 5 TB above (for example 1, 2, 3, 4, 5, 10, 15, 20). Any other value is rejected with a validation error that lists the allowed sizes. If omitted, the smallest allowed size is used. | [optional]
